# Landing page photography slots

The public site looks for these files. Until a file exists, an elegant contour-map
backdrop is shown in its place, so the site never looks broken.

| File | Where it appears | Suggested subject | Size (px) |
|---|---|---|---|
| `hero-1.jpg` | Hero slide 1 (first screen) | Aerial view of land / surveyed plots at golden hour | 2400 × 1600 |
| `hero-2.jpg` | Hero slide 2 | Modern residential development | 2400 × 1600 |
| `hero-3.jpg` | Hero slide 3 | Luxury architectural photography | 2400 × 1600 |
| `about.jpg` | About section (portrait) | Close aerial or ground view of plots | 1200 × 1500 |
| `development.jpg` | Business benefits band (darkened) | Wide development or landscape | 2400 × 1200 |
| `auth-panel.jpg` | Sign-in page side panel (desktop) | Calm landscape | 1600 × 2000 |
| `og-image.jpg` | Link previews (WhatsApp, social) | Brand image with “GUMADO” | 1200 × 630 |

Keep each file under ~350 KB (export as progressive JPEG at quality 70–78, or
use WebP and update the file names in `src/pages/landing/LandingPage.tsx`).
Use only photographs you own or have licensed. Don't use photos of real
customers' properties without their permission.
